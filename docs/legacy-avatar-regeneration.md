# Regenerated original six avatars

The original mochi, kuma, usagi, kaeru, pan and piyo illustrations were redrawn with the built-in ImageGen tool to match the detailed chibi collection: large shiny eyes, varied outlines, soft warm shading, fur/feather details and small crewneck busts. Names and component paths are retained.

Sources and full generation prompts: `characters/<name>/{directions,reactions}.png` and `*-prompt.txt` (local, ignored). Iteration prompts repaired floating-symbol margins, removed chick whiskers and aligned bunny torsos. Local original atlas backups: `characters/legacy-regeneration/previous-atlases/`.

Final runtime assets: `public/avatars/<name>-{directions,reactions}.webp`, RGBA 960×960. Each character has nine directions and nine expressions. Numerical verification reports and source hashes are recorded in `characters/legacy-regeneration/manifest.json`; all frames were visually reviewed before replacement.

The local demo uses these replacements automatically. No remote deployment was performed.
