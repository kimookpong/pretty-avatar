# Avatar collection: 30 animals + 30 people

## Deliverable

60 distinct colour-style chibi characters matching the supplied visual direction.
Each has a directions PNG, a reactions PNG, two aligned 960×960 WebP atlases,
numeric validation, visual review, and a downloadable entry in the demo.
The original six characters remain available separately from this new collection.

## Execution

1. Pilot: animal-tiger and human-curly-glasses. Check small-size readability,
   all nine directions, matching identity and all nine expressions.
2. Generate remaining directions using the per-character catalog descriptions.
3. Generate reactions using each character's own directions as reference.
4. Screen, stage, build and verify each pair; redraw failures with targeted prompts.
   Inspect built atlases too: cleaning may remove symbols near cell boundaries.
   The builder fits the combined directions/reactions extents, shrinking both
   uniformly when a heart, sparkle or sleep symbol would otherwise be clipped.
5. Mark each individually reviewed character verified and sync the demo cast.
6. Run Python tests, React tests, skill checks, TypeScript and production site build.

## Files and resume

- Catalog and creation format: `skills/pretty-avatar/reference/`.
- Prompts and source PNGs: `characters/<preset-id>/` (local, ignored by Git).
- Resume manifest: `characters/collection/manifest.json` (local, ignored by Git).
- Deliverable atlases and validation metadata: `public/avatars/` (tracked).
- Demo cast: `site/generated-cast.ts`, generated by `npm run sync:collection`.

```bash
.venv/bin/python skills/pretty-avatar/scripts/collection.py status
.venv/bin/python skills/pretty-avatar/scripts/collection.py build --id animal-tiger
# Only after visual inspection of the built sheets:
.venv/bin/python skills/pretty-avatar/scripts/collection.py build --id animal-tiger --visual-reviewed
npm run sync:collection
npm run build:site
```

Generation uses the built-in image tool, one call per sheet. No live Images API
requests are issued by prepare/build/status. Do not present pending presets as
ready-made downloadable characters. Creating the local demo does not deploy it.

Visual review is bound to SHA-256 hashes of both source sheets. Replacing either
source requires a new review. Builds stage and validate before replacing public
atlases, and concurrent progress updates merge under a manifest lock.

## Completed collection

- 60/60 verified: 30 animals and 30 people, 120 RGBA WebP atlases at 960×960.
- 18 cells per character: nine directions and nine expressions, 1,080 cells total.
- Atlases total 21.29 MiB. Each character has public JSON validation metadata.
- Demo has 66 entries including the original six, animal/person filters, downloads,
  and viewport-based mounting to limit active cursor listeners.
- React tests: 18 passed. Python pipeline/collection tests: 19 passed.
- Skill validation, synchronized references, TypeScript and production site build passed.
- Browser checks: 30 people, 36 animals including original six; choosing a character
  updates the playground snippet; Thai filters work; no console errors observed.
- The fitted-hijab preset uses a simple hood and high-neck top to keep the lower body
  stable. Raccoon uses a teal shirt. Catalog descriptions match these revisions.
- Sources/prompts remain locally in `characters/`; original generated images are
  preserved in the built-in tool's output directory. No remote deployment performed.
